# Max Johnson Portfolio

A clean, responsive personal portfolio site.

## Structure

- `index.html` — semantic page structure and content
- `css/`
  - `variables.css` — design tokens (colors, spacing, transitions)
  - `base.css` — reset and global element styles
  - `layout.css` — containers, section wrappers, headers
  - `components.css` — reusable UI components (buttons, tags, cards, animations)
  - `sections.css` — section-specific styles
  - `responsive.css` — mobile breakpoint overrides
- `js/`
  - `main.js` — entry point
  - `nav.js` — mobile navigation logic
  - `reveal.js` — scroll-triggered fade-in animation

## Run locally

Open `index.html` in any modern browser, or serve with a static server:

```bash
python3 -m http.server 8000
```
